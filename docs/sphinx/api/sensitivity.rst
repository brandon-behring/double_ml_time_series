Rosenbaum Bounds (``dml_ts.sensitivity.rosenbaum``)
---------------------------------------------------

The scalar diagnostic applies an assumed log-gamma bias to the estimate and its
standard error. A matched-design Rosenbaum analysis requires assignment and
matched-set information. Check crossing_observed before reporting a threshold.
