# How well does a causal estimate carry forward?

A public estimate that door-to-door canvassing raised turnout by **2.25 percentage points** came within **0.15 points** of the pooled result in six later cities. An activity-reminder estimate from earlier patients missed the later randomized effect by **0.059 log units**, with a 95% interval spanning zero. And when the same GDP model was given economic revisions it could never have seen, its forecast error looked smaller. These examples answer different questions about a validation date. [Canvassing](forward/canvassing.md) · [Reminders](forward/reminders.md) · [GDP vintages](forward/gdp.md)

## What was known at the cutoff?

For the trials, the primary forecast is the effect estimated using information from the earlier population. New people, later randomized assignments and later outcomes enter evaluation. We report the signed difference **forecast minus later effect**, its uncertainty, and performance against a zero-effect forecast. A later trial supplies a noisy estimate of the causal effect in its population. For GDP, a later release supplies an observed forecasting target. Its subsequent revisions are a separate target. A good forecast of the observed outcome alone leaves open what would have happened under a different intervention.

## What did the 2018 journals validate?

The print-issue roster contains **215 items**, including 15 front-matter records. Screening principal claims identified **158 original empirical papers** and **three** whose headline analysis projected an intervention or place effect and **five** that predicted later outcomes. The spreadsheet records what each source actually tested, the comparator and whether sufficient data can be acquired. A study estimating a historical effect or following the same participants through time need not promise a forecast for a fresh policy episode. These counts describe the review of principal claims in these three volumes. The access checks distinguish twelve cases where analysis inputs were sampled from 117 with a publisher-linked deposit whose contents were not inspected. [Journal screen and acquisition priorities](forward/journals.md) · [Paper-by-paper ledger](forward/journals-2018.csv)

Two papers illustrate what “validation” covered. Fieler, Eslava and Xu fitted a trade model using manufacturing plants before Colombian liberalization and compared its predictions with post-reform outcomes. Fowlie, Greenstone and Wolfram compared engineering projections with measured savings in a Michigan weatherization evaluation. The first compares outcomes after a reform. The second directly examines a projected intervention response. [Colombia paper](https://doi.org/10.1257/aer.20150796) · [Weatherization paper](https://doi.org/10.1093/qje/qjy005)

## Reproduce the results

Run from the repository root. The runner gives each of up to four studies one numerical-library thread. A PDF text extractor (Poppler) and base R are needed for the primary-source suite. With sources cached, the runs can be repeated locally. The underlying GDP archive and survey extract include historical deadlines, release dates and first-public values.

```bash
audit=docs/audits/2026-11-19_time_series_dml
export DML_TS_BENCHMARK_CACHE="${XDG_CACHE_HOME:-$HOME/.cache}/dml-ts/external"
uv run --locked python "$audit/external/run.py" --suite forward --jobs 4
uv run --locked python "$audit/external/run.py" reminder-cohorts gdp-vintages
uv run --locked python "$audit/external/forward/journals.py" --verify-roster --cache-dir "$DML_TS_BENCHMARK_CACHE"
DML_TS_EXTERNAL_REPLAY=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  uv run --locked --extra dev python -m pytest -q test/integration/test_forward*.py \
    test/integration/test_{open_bandit,bracero,teacher_pay,weatherization}_benchmark.py
PYTHONPATH="../temporalcv/src" uv run --locked python "$audit/external/run.py" --suite forward
```

The Python repository already uses `temporalcv` for temporal splitting and sampling variance. Here the splits act on enrollment dates and quarterly origins. Study-specific code maps those dates to complete outcome windows, experimental comparisons and the data vintage available to each analyst. The original ten published replications remain the default runner selection. Use `--suite all` for the combined studies, including the [separate environment for the Italian author code](11-external-replication-benchmarks.md#reproduce-the-checks).
