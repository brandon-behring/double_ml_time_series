# Could the Mexican school subsidy’s enrollment effect have been predicted?

For children aged 12–15, Todd and Wolpin’s structural model predicted subsidy effects of **6.4 percentage points for girls and 7.7 for boys** in the comparison using the 1998 control group. The village-randomized attendance contrasts we recovered were **7.96 and 3.81 points**. The prediction was closer for girls. For boys a zero-effect prediction had almost exactly the same absolute error as the model. [Published study](https://doi.org/10.1257/aer.96.5.1384) · [Wolpin’s summary of the published estimates, slide 129](https://cowles.yale.edu/sites/default/files/2023-12/wolpin1.pdf#page=129)

| Group | 1998 control attending | 1998 treated attending | Experiment (pp) | Model using 1998 controls (pp) | Forecast minus experiment (pp) | Forecast using 1997 controls (pp) |
|---|---:|---:|---:|---:|---:|---:|
| Girls | 117 / 176 | 166 / 223 | 7.96 | 6.40 | −1.56 | 7.40 |
| Boys | 132 / 182 | 200 / 262 | 3.81 | 7.70 | +3.89 | 10.80 |

The executable reads the authors’ Tables 11 and 12 in the working paper. For each experimental arm it finds the only possible integer attendance count given the sample size and printed rate. For the model contrast it subtracts actual attendance in the control population from its simulated attendance with the subsidy. The resulting experimental and predicted effects round to all four figures in Wolpin’s published-study summary. The working paper prints 7.9 for girls when it subtracts already rounded rates. Counts give 7.96. The reported experimental standard errors are 4.6 and 4.2 points. Joint uncertainty for prediction minus experiment requires the sampling covariance with the model and shared control observations. The published table does not supply this covariance. [Tables, fitted samples and definitions, pp. 29–31 and 47–48](https://economics.sas.upenn.edu/sites/default/files/filevault/working-papers/03-022.pdf) · [Reconstruction](../external/forward/progresa.py)

**The information available at the time matters even here.** Before rollout, an operator could use the 1997 state of the control population. The corresponding table-based gaps against the eventual experimental effects are −0.56 and +6.99 points. The 1998-control forecasts condition on a later observed comparison population. The working-paper specification explicitly describes the 1998 controls as part of its estimation information. The final article describes its validation model as fitted without post-program data. We distinguish these versions and do not certify a dated pre-rollout fit from the reported tables. For a public analyst the confirmed prediction is a later publication, with no contemporaneous documented model freeze in these sources. With no untreated-period variation in the subsidy, a baseline-only DML regression cannot learn the subsidy effect without additional structure. [Design and baseline survey documentation](https://doi.org/10.7910/DVN/05BMJY) · [Published estimand](https://doi.org/10.1257/aer.96.5.1384)

The table replay uses reported arm sizes, attendance rates and simulated model outputs. A 2015 capture of the original AEA ZIP also supplies the household data, programs and original documentation. [Original archive copy](https://web.archive.org/web/20150921083256id_/https://www.aeaweb.org/aer/data/dec06/20031016_data.zip) · [Current publisher deposit](https://doi.org/10.3886/E116240V1)

## Direct check on the archived households

The original AEA archive's validation file contains **19,500 child-wave records**. Selecting poor households in 1998, ages 12–15, with observed attendance recovers every numerator and denominator in the table above from individual records. Villages were randomly assigned. Clustering the difference of child-level means by the full state–municipality–locality identifier gives an SE of **5.33 points across 192 villages for girls** (95% interval −2.55 to +18.48) and **4.97 across 196 villages for boys** (−6.00 to +13.61). These are new village-clustered uncertainty estimates. The model and experiment share controls, so simply adding a model variance to these estimates would not give a valid error interval. [Raw-data replay](../external/forward/progresa_raw.py) · [Original source files](https://web.archive.org/web/20150921083256id_/https://www.aeaweb.org/aer/data/dec06/20031016_data.zip)

The archived estimation file has **14,039 rows, including 3,923 control observations in 1998**. The validation file adds 5,461 treated 1998 rows. All 14,039 shared child-wave identifiers match exactly, although father's age differs for 3,872 and a 1998 missing-grade indicator differs for 425. The fields used in the attendance calculation agree. File contents establish what was available to the archived estimator. Determining which rows entered the optimized likelihood requires the executable specification.

I also compiled the authors' original Fortran ASCII reader and original subsidy-budget subroutine with GNU Fortran. The reader independently recovered the same eight arm totals from its formatted raw input. For a single attending child with six completed grades and other cash flows set to zero, the original policy routine returned **1,745.15** for a girl and **1,662.05** for a boy in the model's deflated peso units. The source sets these to 1,890/1.083 and 1,800/1.083. The optional check runs with `uv run --locked python docs/audits/2026-11-19_time_series_dml/external/forward/progresa_raw.py --cache-dir /tmp/dml-external-bench-cache --check-fortran`. The ordinary study command only requires Python and Poppler. [Fortran verification](../external/forward/progresa_raw_check.f90)

**Structural prediction provenance.** Both archived simulation build scripts refer to an absent file named `constraint2.f`. The configured simulation reads three absent continuation-value files (`theta.type1` through `theta.type3`), and no simulated-attendance output for the published validation table is included. The archive documents a different filename for the original subsidy constraint, and its long-term simulation source contains a switch for recomputing the continuation values. Changing both the archived build and its simulation configuration would create a reconstructed specification. The 6.4 and 7.7 point behavioral predictions above remain checks against author-published model outputs. The randomized benchmarks and their village-level inference now run from the original microdata.
