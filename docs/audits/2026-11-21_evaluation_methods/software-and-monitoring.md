# Software contracts, sensitivity and deployment claims

Two operational findings survived an executable check. A perfectly calibrated constant 0.5 propensity in a fair lottery can trigger a critical R² alert and suggest retraining. An effect change from zero to 0.000001 with SE 1 on each estimate triggers a critical drift alert; under independent estimates the routine's own two-sided p-value is 0.9999994. These are threshold decisions. Neither can establish degradation in causal accuracy. The zero-baseline nuisance comparison also used to raise a division error. The repaired function reports the R²-point change and an undefined relative percentage when the baseline is zero. The absolute alert thresholds still apply. ## Calibrating a deployed decision

For randomized decisions, compare predicted probabilities with the logged assignment law on eligible decisions. Report calibration and probability loss by event or cohort. For observational assignment, evaluate residual support in the treated and comparison populations. For drift, specify the smallest material change in outcome units, covariance between repeated windows, and a tolerable false-alarm rate across all planned looks. Evaluate the full policy for pausing or retraining on stable and changing simulated trajectories. A warning with no later identifying design is a prompt for investigation.
