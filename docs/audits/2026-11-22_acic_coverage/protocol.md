# ACIC 2019 low-dimensional coverage protocol

This follow-up applies the November 21 evaluation matrix to the independent contest draws. It retains the estimators, learner settings and fivefold split seed used on the 16 development files. The cohort, score, comparison and rejection rule were written before running the estimators on contest outcomes. This is an internal analysis protocol. [Evaluation matrix](../2026-11-21_evaluation_methods/evaluation-matrix.md) · [Development study](../2026-11-21_evaluation_methods/external-control.md) · [Organizer specification](https://sites.google.com/view/acic2019datachallenge/data-challenge)

| Decision | Fixed specification |
|---|---|
| Question | Does the existing cross-fitted augmented inverse-probability weighted (AIPW) procedure achieve nominal 95% coverage of the published population average treatment effect (PATE) under repeated sampling? |
| Cohort | All 3,200 observed files in the low-dimensional challenge. Join the official key by exact filename stem and stratify by organizer DGPid. Require 32 designs with 100 unique files each. Treat one dataset as one Monte Carlo draw. |
| Estimation | Use the development-file evaluator unchanged for the primary score. Standardize within each training fold. Fit separate ridge outcome models in the two arms (penalty 1) and logistic treatment probabilities (inverse penalty 1). Bound probabilities to [0.01, 0.99] in the AIPW score. Compute the mean of held-out scores and a Wald interval using their sample SD divided by √n, with a standard-normal critical value. |
| Primary evidence | Count inclusive interval hits by design. Report all planned draws, failures, exact two-sided 95% binomial Monte Carlo intervals, empirical SD, mean reported SE and mean interval width. A missing interval is a miss for the planned-draw coverage rate. A point estimate's errors or widths require a valid fit. |
| Rejection rule | For each of 32 designs, test undercoverage against 95% using the one-sided lower-tail binomial probability. Apply Holm adjustment to all 32 primary p-values with familywise level 0.05. No rejection at this sample size leaves a range of coverage rates plausible. |
| Point comparators | On identical rows compare AIPW with the mean cross-fitted arm-outcome contrast (standardization) and the unadjusted arm difference. Report bias, RMSE and paired AIPW-minus-standardization squared-error differences, including their Monte Carlo SE. The unadjusted contrast can be confounded. Report ordinary PLR as a separate diagnostic because variance-weighted effects can differ from PATE under effect heterogeneity. |
| Prediction and support | Score marginal outcome and treatment predictions against the training-fold mean outcome and treatment prevalence. Calculate held-out factual MSE for each arm model, clipped-probability fraction and inverse-weight effective sample size in each observed arm. Calculate descriptive within-design Spearman correlations between per-draw prediction skill and absolute AIPW error. No cutoff for nuisance loss is a causal validity criterion. |
| Comparison across designs | Report counts of designs meeting a criterion. Avoid averaging raw effect errors over disparate outcome scales. Flag data-driven illustrative design choices as such. Never infer bias, undercoverage or a lack of effect from one draw. |
| Scope | Released files have exchangeable observations under the organizers’ designs. Row number has no treatment or label-release clock. Serial dependence, clustered assignment and effect transport require separate longitudinal evidence. |

The official truth supplies the target only for scoring after fitting. Report numerical failures and convergence warnings explicitly, retain the original inputs in a hash-checked cache, and compare the primary estimates independently on one file per design.
