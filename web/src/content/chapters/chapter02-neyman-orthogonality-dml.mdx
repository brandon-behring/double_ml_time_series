# Neyman Orthogonality and Double Machine Learning

## Introduction

In Chapter 1, we established the Frisch–Waugh–Lovell (FWL) theorem as a powerful tool for causal inference under unconfoundedness. The FWL approach allows us to estimate treatment effects by "partialling out" confounders through residualization:

$$
\begin{aligned}
\tilde{T}_i &= T_i - \mathbb{E}[T_i \mid X_i] \\
\tilde{Y}_i &= Y_i - \mathbb{E}[Y_i \mid X_i] \\
\hat{\tau} &= \frac{\text{Cov}(\tilde{T}_i, \tilde{Y}_i)}{\text{Var}(\tilde{T}_i)}
\end{aligned}
$$

With full-rank linear controls, the finite-sample FWL identity reproduces the treatment coefficient from the joint least-squares regression. A causal reading additionally requires a justified assignment model, appropriate adjustment, and residual treatment variation.

### The regularization bias problem

However, modern causal inference often involves:

- **High-dimensional confounders**: $p > n$ or $p \approx n$, where linear regression fails
- **Complex nonlinear relationships**: true conditional expectations are nonlinear
- **Flexible machine learning models**: Lasso, Ridge, Random Forests, Gradient Boosting, Neural Networks

Regularized prediction can shrink estimated conditional means toward simpler functions. In a score sensitive to first-order nuisance error, that shrinkage can overwhelm the variation used for ordinary root-$n$ inference. Whether the estimated slope converges to its target depends on the score, the size of those errors and the identifying assumptions.

### The Double Machine Learning solution

**Double Machine Learning (DML)** solves this problem through two key innovations:

1. **Neyman orthogonality**: structure the estimation problem so that first-order bias in nuisance functions doesn't affect the treatment effect estimate.
2. **Sample splitting (cross-fitting)**: use different data to estimate nuisance functions and the final parameter, preventing overfitting bias.

The result is a $\sqrt{n}$-consistent, asymptotically normal estimator for $\tau$ even when using flexible machine learning methods with regularization bias.

This chapter develops these ideas rigorously, starting with the mathematical concept of Neyman orthogonality.

## Neyman orthogonality: the key insight

### Motivation: when does bias in nuisance functions matter?

Consider a general moment condition:

$$
\mathbb{E}[\psi(W_i; \tau, \eta_0)] = 0
$$

where:

- $W_i = (Y_i, T_i, X_i)$ is the observed data
- $\tau$ is the target parameter (treatment effect)
- $\eta_0$ represents nuisance functions we must estimate (e.g., $\mu_0(x) = \mathbb{E}[Y \mid X=x]$, $m_0(x) = \mathbb{E}[T \mid X=x]$)
- $\psi$ is the score function

In the partialling-out score, both conditional means enter as residuals:
$$
\psi(W;\tau,\mu,m)=(T-m(X))\{Y-\mu(X)-\tau(T-m(X))\}.
$$
Here $\mu_0(X)=\mathbb E[Y\mid X]$ and $m_0(X)=\mathbb E[T\mid X]$.

**The problem**: if we estimate $\eta_0$ with bias, we get $\hat{\eta}$ such that $\hat{\eta} - \eta_0 = r_n$ (some estimation error). This error propagates to our estimate of $\tau$.

**The question**: under what conditions does this nuisance estimation error **not** affect our estimate of $\tau$ at first order?

### Neyman orthogonality condition

<Theorem kind="definition" n="2.1" name="Neyman Orthogonality" id="def-neyman-orthogonality">

<MarginNote title="Key insight">Orthogonality means first-order bias in nuisance $\hat{\eta}$ doesn't affect $\hat{\tau}$. This is why ML works.</MarginNote>

A score function $\psi(W; \tau, \eta)$ satisfies the **Neyman orthogonality condition** at $(\tau_0, \eta_0)$ if:

$$
\left. \frac{\partial}{\partial \eta} \mathbb{E}[\psi(W; \tau_0, \eta)] \right|_{\eta = \eta_0} = 0
$$

In other words, the expected score is insensitive to small perturbations in $\eta$ around the true value $\eta_0$, when $\tau = \tau_0$.

**Intuition**: the "orthogonality" refers to the fact that the gradient of $\mathbb{E}[\psi]$ with respect to $\eta$ is orthogonal (perpendicular) to the space of perturbations $\eta - \eta_0$.

This means:

- First-order bias in $\hat{\eta}$ does not create first-order bias in $\hat{\tau}$.
- We only suffer from **second-order** bias: $O(\|\hat{\eta} - \eta_0\|^2)$.
- If $\|\hat{\eta} - \eta_0\| = o_p(n^{-1/4})$, then the second-order bias is $o_p(n^{-1/2})$, which is asymptotically negligible.

</Theorem>

### Example: partially linear model

<Theorem kind="definition" n="2.2" name="Partially Linear Model" id="def-partially-linear-model">

The **partially linear model** specifies:

$$
\begin{aligned}
Y_i &= \tau \cdot T_i + g_0(X_i) + \epsilon_i \\
T_i &= m_0(X_i) + v_i
\end{aligned}
$$

where:

- $Y_i$ is the outcome, $T_i$ is treatment, $X_i$ are confounders
- $g_0(X)$ is the outcome regression component at zero treatment
- $m_0(X) = \mathbb{E}[T \mid X]$ is the conditional mean of treatment (the propensity for binary treatment)
- $\mathbb{E}[\epsilon_i \mid T_i, X_i] = 0$ (exogeneity)
- $\mathbb{E}[v_i \mid X_i] = 0$ (treatment residual is mean-zero)

</Theorem>

There are two useful orthogonal scores in this model. The IV-type score uses the structural outcome component $g$:
$$
\psi_{\mathrm{IV}}(W;\tau,g,m)=(T-m(X))(Y-\tau T-g(X)).
$$
Evaluate its directional derivatives at the true functions. For an arbitrary square-integrable perturbation $h_m(X)$ of $m$, the derivative is $-\mathbb E[h_m(X)\epsilon]=0$. For a perturbation $h_g(X)$ of $g$, the derivative is $-\mathbb E[h_g(X)(T-m_0(X))]=0$. The two conditional mean restrictions above give both equalities. Exercise 2.2 compares this with a genuinely nonorthogonal score.

### The orthogonal score: partialling out

The partialling-out score uses the two conditional means that can each be fitted as a prediction problem:

$$
\psi_{\text{DML}}(W_i; \tau, \eta) = (T_i - m(X_i)) \cdot (Y_i - \ell(X_i) - \tau \cdot (T_i - m(X_i)))
$$

where $\eta = (\ell, m)$ and:

- $\ell(X_i) = \mathbb{E}[Y_i \mid X_i]$ is the **reduced form**, the conditional mean of the outcome.
- $m(X_i) = \mathbb{E}[T_i \mid X_i]$ is the **first stage**, the conditional mean of treatment.

Under the model, $\ell_0(X) = \mathbb{E}[Y \mid X] = \tau_0 \cdot m_0(X) + g_0(X)$.

With binary treatment, heterogeneous effects change the interpretation of the slope. Suppose two equally sized groups have treatment probabilities 0.1 and 0.5 and effects 0 and 2. The population average effect is 1. The partially linear score weights the groups by their conditional treatment variances, 0.09 and 0.25, and gives a slope of 1.470588 even with both population nuisance functions. An average effect requires a score targeting the population mean contrast.

<Theorem kind="theorem" n="2.1" name="Neyman Orthogonality of DML Score" id="thm-dml-orthogonality">

<MarginNote title="Why $\ell_0$?">The proof shows that using $\ell_0(X) = \mathbb{E}[Y \mid X]$ instead of $g_0(X)$ achieves orthogonality.</MarginNote>

The score function $\psi_{\text{DML}}(W; \tau, \eta)$ satisfies the Neyman orthogonality condition at $(\tau_0, \eta_0)$ where $\eta_0 = (\ell_0, m_0)$.

</Theorem>

<Theorem kind="proof">

We need to verify:

$$
\left. \frac{\partial}{\partial \ell} \mathbb{E}[\psi_{\text{DML}}(W; \tau_0, \eta)] \right|_{\eta = \eta_0} = 0
$$

and similarly for $m$.

First, expand the expectation:

$$
\begin{aligned}
\mathbb{E}[\psi_{\text{DML}}(W; \tau_0, \eta)]
&= \mathbb{E}[(T - m(X)) \cdot (Y - \ell(X) - \tau_0 (T - m(X)))] \\
&= \mathbb{E}[(T - m(X)) \cdot (Y - \ell(X) - \tau_0 T + \tau_0 m(X))]
\end{aligned}
$$

Substitute the true model $Y = \tau_0 T + g_0(X) + \epsilon$ and $T = m_0(X) + v$:

$$
\begin{aligned}
&= \mathbb{E}[(v + m_0(X) - m(X)) \cdot (\tau_0 T + g_0(X) + \epsilon - \ell(X) - \tau_0 T + \tau_0 m(X))] \\
&= \mathbb{E}[(v + m_0(X) - m(X)) \cdot (g_0(X) - \ell(X) + \tau_0 m(X) + \epsilon)]
\end{aligned}
$$

Now note that $\ell_0(X) = \mathbb{E}[Y \mid X] = \tau_0 m_0(X) + g_0(X)$. At $\eta = \eta_0$, this becomes:

$$
\begin{aligned}
&= \mathbb{E}[v \cdot (g_0(X) - \ell_0(X) + \tau_0 m_0(X) + \epsilon)] \\
&= \mathbb{E}[v \cdot (g_0(X) - (\tau_0 m_0(X) + g_0(X)) + \tau_0 m_0(X) + \epsilon)] \\
&= \mathbb{E}[v \cdot \epsilon] = 0
\end{aligned}
$$

by $\mathbb{E}[v \mid X] = 0$ and $\mathbb{E}[\epsilon \mid T, X] = 0$.

Consider any square-integrable changes $h(X)$ and $k(X)$ in the outcome and treatment nuisance functions. Along the path $\ell=\ell_0+\delta h$ and $m=m_0+\delta k$, the population score at the true slope equals

$$
\mathbb{E}\big[(v-\delta k)(\epsilon+\delta(\tau_0 k-h))\big].
$$

Its derivative at zero is $\mathbb{E}[v(\tau_0 k-h)-k\epsilon]=0$, since both $v$ and $\epsilon$ have conditional mean zero given $X$. The remaining term is $\delta^2\mathbb{E}[k(h-\tau_0 k)]$. In a balanced example with $\tau_0=2$, $h=k=X$, and $X$ equally likely to be $-1$ or $1$, the score error is exactly $-\delta^2$. Halving both nuisance errors quarters the score error.

</Theorem>

### Why orthogonality enables machine learning

Regularization changes fitted nuisance functions. Their convergence rates depend on the model, features, dependence and training size. For the partialling-out score with held-out observations, write $a=\widehat m-m_0$ and $b=\widehat\ell-\ell_0$. Its population drift at the true slope is $\mathbb E[a(b-\tau_0a)]$. A sufficient condition for this error to be negligible on the root-$n$ scale is
$$
\|a\|_2(\|b\|_2+|\tau_0|\,\|a\|_2)=o_p(n^{-1/2}).
$$
Both errors being $o_p(n^{-1/4})$ suffices. Other combinations can also satisfy the product condition. The condition bounds the drift and nothing else: with $\tau_0=0$ it reduces to $\|a\|_2\|b\|_2=o_p(n^{-1/2})$, which a fast enough treatment fit meets even when the outcome fit does not converge. The usual DML regularity conditions therefore also require each error to vanish, $\|a\|_2=o_p(1)$ and $\|b\|_2=o_p(1)$, which is what controls the empirical score with fitted nuisances. No learner family alone guarantees a rate. Identification and variation in residual treatment are further requirements.

## The Double Machine Learning algorithm

Orthogonality controls the drift of the population score. Flexible nuisance fits also require control of their dependence on the observations used to estimate the slope.

### The overfitting problem

A highly adaptive nuisance fit can use an observation's own outcome when constructing its prediction for that same observation. A learner that interpolates both training responses makes their training residuals zero, leaving no slope to estimate. Held-out predictions remove that direct reuse. In simpler parametric settings, using the same observations can still give valid inference under appropriate regularity conditions.

### Sample splitting: the DML solution

**Double Machine Learning** solves this via **sample splitting** (also called **cross-fitting**):

<Theorem kind="definition" n="2.3" name="Cross-Fitting Procedure" id="def-cross-fitting">

<MarginNote title="Why $K$-fold?">$K=5$ is the default. Larger $K$ uses more data for nuisance estimation but increases computation.</MarginNote>

On independent observations, divide the sample into a fixed number $K$ of folds. For each fold, fit both nuisance functions on the other folds and predict the held-out rows. Set $V_i=T_i-\widehat m^{(-k(i))}(X_i)$ and $U_i=Y_i-\widehat\ell^{(-k(i))}(X_i)$.

The pooled-score estimator (DML2), used by the repository's ordinary PLR, is
$$
\widehat\tau=\frac{\sum_i V_i U_i}{\sum_i V_i^2}.
$$
DML1 first computes the slope within each fold, then averages those slopes. The pooled estimator weights each fold slope by its sum of squared treatment residuals, so the two estimates can differ in finite samples.

</Theorem>

For independent observations, each held-out outcome is excluded from the fit that predicts it. Shared households, panels or serial dependence require a split and uncertainty calculation suited to their sampling and assignment structure.

### Why K-fold? Why not just 2-fold?

With $K$ equal-sized folds, each nuisance fit uses about $(K-1)n/K$ observations. Two folds require fewer fits, while five folds give each learner about four fifths of the sample for training. Optimizing computation and predictive performance depends on the application. The usual fixed-$K$ DML argument allows any fixed integer $K\ge2$ under its regularity conditions. Leave-one-out cross-fitting has $K=n$ and requires a different argument. For a dated deployment question, training information must also be available at the prediction origin.

### Variance estimation and inference

After obtaining $\hat{\tau}_{\text{DML}}$, we need the standard error for confidence intervals and hypothesis tests.

<Theorem kind="theorem" n="2.2" name="Asymptotic Normality of DML" id="thm-dml-asymptotic-normality">

<MarginNote title="Inference">The theorem gives asymptotic coverage under its sampling and nuisance-rate conditions.</MarginNote>

For independent observations, fixed-fold cross-fitting, the nuisance product rate above, positive residual treatment variation and suitable moment bounds, the DML estimator satisfies:

$$
\sqrt{n}(\hat{\tau}_{\text{DML}} - \tau_0) \xrightarrow{d} N(0, \Sigma)
$$

where the asymptotic variance is:

$$
\Sigma = \mathbb{E}\left[\frac{\psi(W_i; \tau_0, \eta_0)^2}{(\mathbb{E}[\partial_\tau \psi(W_i; \tau_0, \eta_0)])^2}\right]
$$

</Theorem>

<Theorem kind="remark" name="Practical Variance Estimation">

The asymptotic variance can be consistently estimated by:

$$
\hat{\Sigma} = \frac{1}{n} \sum_{i=1}^n \frac{\psi(W_i; \hat{\tau}_{\text{DML}}, \hat{\eta}^{(-k(i))})^2}{\left(\frac{1}{n}\sum_{i=1}^n \partial_\tau \psi(W_i; \hat{\tau}_{\text{DML}}, \hat{\eta}^{(-k(i))})\right)^2}
$$

where $k(i)$ denotes the fold containing observation $i$, and $\hat{\eta}^{(-k(i))}$ is the nuisance estimate from the complement.

</Theorem>

**Confidence interval** (95%):

$$
\hat{\tau}_{\text{DML}} \pm 1.96 \cdot \sqrt{\frac{\hat{\Sigma}}{n}}
$$

## Python implementation with EconML

Microsoft's **EconML** library provides established implementations of DML estimators. Let's see how to apply DML to the partially linear model.

### Basic DML example

```python
import numpy as np
from econml.dml import LinearDML
from sklearn.ensemble import RandomForestRegressor
from sklearn.linear_model import LassoCV
# Set seed for reproducibility
np.random.seed(42)
n = 2000
# Generate high-dimensional confounders (p = 20)
X = np.random.randn(n, 20)
# Nonlinear treatment assignment
T = (X[:, 0]**2 + X[:, 1]**2 +
     0.5 * X[:, 2] * X[:, 3] +
     np.random.randn(n))
# Nonlinear outcome with treatment effect tau = 2.5
Y = (2.5 * T +                           # Treatment effect
     np.sin(X[:, 0]) +                   # Nonlinear confounder
     np.exp(X[:, 1] / 2) +               # Nonlinear confounder
     X[:, 2]**2 +                        # Nonlinear confounder
     np.random.randn(n))                 # Noise
# DML estimator with Random Forest for nuisance functions
dml = LinearDML(
    model_y=RandomForestRegressor(n_estimators=100, max_depth=5,
                                   min_samples_leaf=20, random_state=42),
    model_t=RandomForestRegressor(n_estimators=100, max_depth=5,
                                   min_samples_leaf=20, random_state=42),
    discrete_treatment=False,
    cv=5,  # 5-fold cross-fitting
    random_state=42
)
# Fit DML estimator
dml.fit(Y, T, X=X, W=None)
# Get treatment effect estimate
tau_dml = dml.ate(X=X)
print(f"True ATE: 2.50")
print(f"DML Estimate: {tau_dml:.3f}")
# Confidence interval
ci_lower, ci_upper = dml.ate_interval(X=X, alpha=0.05)
print(f"95% CI: [{ci_lower:.3f}, {ci_upper:.3f}]")
# Compare to OLS adjusted for the same 20 covariates
from sklearn.linear_model import LinearRegression
X_T = np.column_stack([T, X])
adjusted_ols = LinearRegression().fit(X_T, Y)
tau_adjusted = adjusted_ols.coef_[0]
print(f"Adjusted OLS: {tau_adjusted:.3f}")
```

**Measured output with EconML 0.16.0**

```
True ATE: 2.50
DML Estimate: 2.407
95% CI: [2.343, 2.471]
Adjusted OLS: 2.501
```

The true slope is 2.5. The forest estimate misses it by 0.093 and
its interval excludes it. OLS adjusts for the same 20 covariates and
gives 2.501 on these observations. A single dataset supplies an estimation
error. Bias and coverage require repeated draws.

### Inspecting first-stage fit quality

Good DML performance requires good first-stage predictions. Let's diagnose:

```python
from econml.dml import LinearDML
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import r2_score, mean_squared_error

# Same DGP
np.random.seed(42)

X = np.random.randn(n, 20)

# Manually perform cross-fitting to inspect first stages
from sklearn.model_selection import KFold
kfold = KFold(n_splits=5, shuffle=True, random_state=42)
first_stage_T_r2 = []
first_stage_Y_r2 = []
for train_idx, test_idx in kfold.split(X):
    X_train, X_test = X[train_idx], X[test_idx]
    T_train, T_test = T[train_idx], T[test_idx]
    Y_train, Y_test = Y[train_idx], Y[test_idx]
    # Fit first-stage models
    model_T = RandomForestRegressor(n_estimators=100, max_depth=5,
                                     min_samples_leaf=20, random_state=42)
    model_Y = RandomForestRegressor(n_estimators=100, max_depth=5,
                                     min_samples_leaf=20, random_state=42)
    model_T.fit(X_train, T_train)
    model_Y.fit(X_train, Y_train)
    # Evaluate on held-out fold
    T_pred = model_T.predict(X_test)
    Y_pred = model_Y.predict(X_test)
    first_stage_T_r2.append(r2_score(T_test, T_pred))
    first_stage_Y_r2.append(r2_score(Y_test, Y_pred))
print("First-Stage Diagnostics:")
print(f"E[T|X] R^2: {np.mean(first_stage_T_r2):.3f} (+/-{np.std(first_stage_T_r2):.3f})")
print(f"E[Y|X] R^2: {np.mean(first_stage_Y_r2):.3f} (+/-{np.std(first_stage_Y_r2):.3f})")
# Compare both losses with a baseline on the same held-out folds.
```

## When DML outperforms classical methods

First choose the intervention, identifying design and target population. In a
randomized trial, report the design-based estimate and compare adjustment
methods on the same eligible units. For a plausibly linear observational
model, compare the residualized estimate with adjusted OLS. For an IV
effect, report the first stage and reduced form on the same sample.

Flexible nuisance regressions are worth testing when substantive knowledge
suggests nonlinearities or interactions and there are enough informative
assignment units. Compare them with a simpler specification on matched folds.
Use held-out prediction losses for the two nuisance roles, residual treatment
variation for support, and paired effect error and interval coverage when
truth is available. Identification assumptions about assignment, observation
and timing are still required.

## Heterogeneous treatment effects with DML

Under a constant identified effect the PLR slope equals the **average treatment effect** (ATE): $\tau = \mathbb{E}[Y_i(1) - Y_i(0)]$. But treatment effects often vary across individuals based on observable characteristics.

### Conditional Average Treatment Effect (CATE)

The **Conditional Average Treatment Effect** is:

$$
\tau(x) = \mathbb{E}[Y_i(1) - Y_i(0) \mid X_i = x]
$$

This tells us: "What is the treatment effect for individuals with characteristics $X = x$?"

**Examples**:

- Insurance: does a competitor price change have larger effects on younger vs. older customers?
- Healthcare: does the medication work better for patients with higher baseline HbA1c?
- Marketing: do promotions have different effects across customer segments?

### Partially linear CATE model

A flexible model for heterogeneous effects:

$$
Y_i = \tau(X_i) \cdot T_i + g_0(X_i) + \epsilon_i
$$

where $\tau(X)$ is the CATE function we want to estimate.

**Simplest case**: linear heterogeneity

$$
\tau(X_i) = \theta_0 + \theta_1 X_{i,1} + \cdots + \theta_p X_{i,p} = (1,X_i')\theta
$$

Then:

$$
Y_i = ((1,X_i')\theta) \cdot T_i + g_0(X_i) + \epsilon_i
$$

**DML for CATE**:

1. **Partial out confounders** from $Y$, $T$, and each interaction $X_j \cdot T$.
2. **Regress** partialled-out $Y$ on partialled-out interactions.
3. **Inference**: use the covariance of the fitted interaction scores under the sampling design.

### Python implementation: CATE with EconML

```python
import numpy as np
from econml.dml import LinearDML
from sklearn.ensemble import RandomForestRegressor
np.random.seed(42)
n = 3000
# Generate confounders
Age = np.random.uniform(25, 75, size=n)  # Customer age
Income = np.random.lognormal(mean=10, sigma=0.5, size=n)  # Income
X = np.column_stack([Age, Income])
# Treatment: competitor price increase (correlated with age)
T = 0.5 * Age + 0.2 * Income / 1000 + np.random.randn(n)
# Heterogeneous effect: younger customers more price-sensitive
tau_true = 5.0 - 0.08 * Age  # Effect decreases with age
Y = tau_true * T + 0.3 * Age + 0.1 * Income / 1000 + np.random.randn(n)
# Estimate CATE with LinearDML
# featurizer=None means we model tau(X) = X'theta (linear heterogeneity)
dml_cate = LinearDML(
    model_y=RandomForestRegressor(n_estimators=100, max_depth=5, random_state=42),
    model_t=RandomForestRegressor(n_estimators=100, max_depth=5, random_state=42),
    featurizer=None,  # Linear CATE model
    fit_cate_intercept=True,
    cv=5,
    random_state=42
)
dml_cate.fit(Y, T, X=X, W=None)
# Get CATE estimates for specific age groups
age_grid = np.array([30, 45, 60])
income_grid = np.array([50000, 50000, 50000])  # Hold income constant
X_grid = np.column_stack([age_grid, income_grid])
cate_est = dml_cate.effect(X_grid)
cate_intervals = dml_cate.effect_interval(X_grid, alpha=0.05)
# Compare to true CATE
tau_true_grid = 5.0 - 0.08 * age_grid
print("Heterogeneous Treatment Effects by Age:")
print("=" * 60)
for i, age in enumerate(age_grid):
    print(f"Age {age:.0f}:")
    print(f"  True CATE:     {tau_true_grid[i]:.3f}")
    print(f"  Estimated:     {cate_est[i]:.3f}")
    print(f"  95% CI:        [{cate_intervals[0][i]:.3f}, {cate_intervals[1][i]:.3f}]")
    print()
```

  True CATE:     1.400

### Interpreting heterogeneity

**Statistical significance of heterogeneity.** Test $H_0: \theta_1 = \theta_2 = \cdots = \theta_p = 0$ (no heterogeneity). Rejection is evidence of effect variation in the tested directions, subject to the model, sampling design and nominal test size.

**Practical significance**:

- **Insurance**: target price changes to age groups with the largest estimated effects.
- **Healthcare**: prescribe medication to patient subgroups where $\tau(X) > \text{threshold}$.
- **Policy**: design interventions conditional on characteristics.

<WarnBox>

**Avoid data dredging.** Pre-specify heterogeneity dimensions based on theory and domain knowledge, not exploratory analysis.

</WarnBox>

## Sensitivity analysis

The observational treatment-effect interpretation here relies on **unconfoundedness**: $\{Y_i(0), Y_i(1)\} \perp\!\!\!\perp T_i \mid X_i$. But what if this fails?

### Omitted variable bias

Suppose $T=m_0(X)+\gamma U+v$ and $Y=\tau T+g_0(X)+\delta U+\epsilon$, with $U,v,\epsilon$ independent of one another and of $X$, centered, and with finite variances. Omitting $U$ leaves residual treatment $V=\gamma U+v$. The population slope after partialling out $X$ is
$$
\tau_X=\tau+\delta\frac{\mathbb E[VU]}{\mathbb E[V^2]}
      =\tau+\frac{\delta\gamma\operatorname{Var}(U)}
                   {\gamma^2\operatorname{Var}(U)+\operatorname{Var}(v)}.
$$
In the example below, $\delta=0.8$, $\gamma=0.5$ and both variances are one. The omitted-variable shift is $0.32$, giving a population slope of $2.32$ when the causal slope is $2$. The shift in a single pair of fitted estimates also contains sampling and learner error.

### Sensitivity bound analysis

Cinelli and Hazlett's robustness value for a linear regression expresses a change in the fitted coefficient in terms of two partial $R^2$ values. One measures the association of an omitted variable with treatment given the observed controls. The other measures its association with outcome given treatment and controls. For a chosen fractional reduction $q$, the robustness value is the tipping-point strength when **both** partial $R^2$ values equal the same value and bias acts in the adverse direction. A significance-based calculation also specifies a significance level and accounts for the change in the standard error.

For example, an RV of 0.15 for a 50% reduction means that equal strengths of 0.15 suffice under that regression calculation. Unequal strengths can also produce the same reduction. Comparing them with observed covariates requires an explicit benchmarking assumption. The following simulation directly reveals the consequence of omitting its known $U$.

### Python implementation: sensitivity analysis

```python
import numpy as np
from econml.dml import LinearDML
from sklearn.ensemble import RandomForestRegressor
np.random.seed(42)
n = 1000
# True DGP with unobserved confounder U
U = np.random.randn(n)  # Unobserved
X = np.random.randn(n, 5)  # Observed confounders
# U affects both T and Y (omitted variable bias)
T = X[:, 0] + X[:, 1] + 0.5 * U + np.random.randn(n)  # gamma = 0.5
Y = 2.0 * T + X[:, 0]**2 + X[:, 1] + 0.8 * U + np.random.randn(n)  # delta = 0.8, tau = 2.0
# DML without observing U (biased estimate)
dml_biased = LinearDML(
    model_y=RandomForestRegressor(n_estimators=50, max_depth=5, random_state=42),
    model_t=RandomForestRegressor(n_estimators=50, max_depth=5, random_state=42),
    cv=5,
    random_state=42
)
dml_biased.fit(Y, T, W=X)
tau_biased = float(dml_biased.ate())
# The same scalar score with the additional confounder
X_with_U = np.column_stack([X, U])
dml_correct = LinearDML(
    model_y=RandomForestRegressor(n_estimators=50, max_depth=5, random_state=42),
    model_t=RandomForestRegressor(n_estimators=50, max_depth=5, random_state=42),
    cv=5,
    random_state=42
)
dml_correct.fit(Y, T, W=X_with_U)
tau_correct = float(dml_correct.ate())
delta_fit = tau_biased - tau_correct
print(f"True one-unit effect: {2.0:.3f}")
print(f"Fit omitting U: {tau_biased:.3f}")
print(f"Fit including U: {tau_correct:.3f}")
print(f"Change between fits: {delta_fit:+.3f}")
print(f"Change as percent of true effect: {100 * delta_fit / 2.0:+.1f}%")
```

**Measured output**

```text
True one-unit effect: 2.000
Fit omitting U: 2.242
Fit including U: 1.951
Change between fits: +0.290
Change as percent of true effect: +14.5%
```

The difference between these two fits measures the change on this simulated dataset. Its population counterpart is the omitted-variable shift derived above. In observed data an analyst can compare tipping-point strengths with substantively credible confounders. A benchmark covariate alone cannot establish that stronger confounding is absent.

## Influence functions and asymptotic theory

For readers interested in deeper theory, we develop the **influence function** perspective on DML.

### What is an influence function?

The **influence function** $\psi$ describes how adding one more observation $W_i$ affects the estimator $\hat{\tau}$.

**Formal definition.** For an estimator $\hat{\tau}_n$ based on $n$ observations, the influence function satisfies:

$$
\sqrt{n}(\hat{\tau}_n - \tau_0) = \frac{1}{\sqrt{n}} \sum_{i=1}^n \psi(W_i; \tau_0, \eta_0) + o_p(1)
$$

**Properties**:

- $\mathbb{E}[\psi(W_i; \tau_0, \eta_0)] = 0$ (mean-zero).
- $\text{Var}(\psi)$ determines the asymptotic variance: $\text{Avar}(\hat{\tau}) = \text{Var}(\psi) / n$.
- Smaller $\text{Var}(\psi) \Rightarrow$ more efficient estimator.

### DML influence function

For the partially linear model, the DML influence function is:

$$
\psi_{\text{DML}}(W_i; \tau, \eta) = \frac{(T_i - m_0(X_i))(Y_i - \ell_0(X_i) - \tau(T_i - m_0(X_i)))}{\mathbb{E}[(T_i - m_0(X_i))^2]}
$$

where $\eta_0 = (\ell_0, m_0)$.

**Key insight**: this influence function is **Neyman orthogonal**:

$$
\left. \frac{\partial}{\partial \eta} \mathbb{E}[\psi_{\text{DML}}(W; \tau_0, \eta)] \right|_{\eta = \eta_0} = 0
$$

This orthogonality property makes DML robust to first-order bias in $\hat{\ell}$ and $\hat{m}$.

### Von Mises expansion

For the unnormalized partialling-out score $s=(T-m)(Y-\ell-\tau(T-m))$, an expansion at the true nuisance functions separates population and sampling errors. Define $V=T-m_0(X)$, $U=Y-\ell_0(X)-\tau_0V$, $a=\widehat m-m_0$ and $b=\widehat\ell-\ell_0$. On a held-out fold, condition on its nuisance training sample. The change in the score at $\tau_0$ is
$$
V(-b+\tau_0a)-aU+a(b-\tau_0a).
$$
The first two terms have mean zero under the conditional mean restrictions. The remaining population drift is $\mathbb E[a(b-\tau_0a)]$. With independent evaluation observations and suitable moment bounds, the centered empirical fluctuation of the score difference is $o_p(n^{-1/2})$ as its $L_2$ norm vanishes. The population drift itself must also be $o_p(n^{-1/2})$. To convert score errors to slope errors, divide by the empirical mean squared treatment residual, which converges to $\mathbb E[V^2]>0$.

### Asymptotic normality proof sketch

For independent observations, assume the preceding product-rate and score-moment conditions, cross-fitting with fixed $K$, and positive finite residual treatment variation. Write $\phi=VU/\mathbb E[V^2]$ for the influence contribution and assume it has positive finite variance. The score expansion gives
$$
\sqrt{n}(\widehat\tau-\tau_0)=n^{-1/2}\sum_{i=1}^n\phi_i+o_p(1)
\quad\Longrightarrow\quad N(0,\mathbb E[\phi^2]).
$$
The central limit theorem applies to the leading mean-zero sum. A consistent estimate of its variance yields asymptotically nominal intervals. In a dependent series the leading variance can include lagged score covariances and the empirical-process argument requires dependence assumptions. Chapter 5 measures how finite-sample coverage changes under serial dependence.

## Practical tips for DML implementation

Based on extensive simulation studies and real-world applications, here are best practices for implementing DML.

### Choosing the right ML method

**Lasso / Ridge** (linear + regularization):

- **Pros**: fast, interpretable, works well with many weak predictors.
- **Cons**: cannot capture nonlinearity, feature selection can be unstable.
- **Best for**: high-dimensional linear settings ($p > n$), sparse signals.
- **Tuning**: use cross-validation for $\lambda$ (penalty parameter).

**Random Forest**:

- **Pros**: handles nonlinearity automatically, robust to overfitting (with enough trees), no feature scaling needed.
- **Cons**: can struggle with linear relationships, memory-intensive for large $n$.
- **Best for**: nonlinear confounding, mixed continuous/categorical features.
- **Tuning**: `n_estimators=100-500`, `max_depth=5-10`, `min_samples_leaf=20-50`.

**Gradient Boosting** (XGBoost / LightGBM / CatBoost):

- **Pros**: often most accurate, handles nonlinearity and interactions well.
- **Cons**: sensitive to hyperparameters, can overfit easily, slower training.
- **Best for**: when maximum accuracy is critical, well-tuned hyperparameters available.
- **Tuning**: `learning_rate=0.01-0.1`, `max_depth=3-6`, `n_estimators=100-1000`.

**Neural Networks**:

- **Pros**: ultimate flexibility, can learn complex patterns.
- **Cons**: requires large $n$, difficult hyperparameter tuning, black box.
- **Best for**: very large datasets ($n > 10{,}000$), image/text confounders.
- **Tuning**: architecture search, regularization (dropout, L2), learning rate scheduling.

### Hyperparameter tuning strategy

Choose the criterion separately for each nuisance. Use held-out squared
error for a conditional mean or a proper probability loss for an assignment
probability. Freeze the settings on independent tuning data or use inner
folds within each outer training set. For a deployment claim, this includes
preprocessing and uses only information available at the forecast origin.
Report the selection rule before evaluating effect error or interval
coverage on independent data or known-truth simulations. Selecting the
largest observed effect on the reporting sample invalidates its ordinary
interval interpretation.

### Diagnosing DML estimates

After obtaining $\hat{\tau}_{\text{DML}}$, always check the following.

**1. First-stage fit quality**

```python

# Inspect residual treatment variation and overlap on the scored units.
```

**2. Residual patterns**

```python

# Plot residuals vs. fitted values

axes[0].scatter(model_t.predict(X), T_resid, alpha=0.3)

axes[1].axhline(y=0, color='r', linestyle='--')

```

**3. Sensitivity to fold assignment.** Run DML with different random seeds for fold splitting. If $\hat{\tau}$ varies substantially (more than 10%), you may have: too few folds (try increasing `cv=5` to `cv=10`), a small sample size relative to model complexity, or instability in first-stage estimates.

**4. Comparison to naive estimators.** Compare $\hat{\tau}_{\text{DML}}$ to the naive OLS estimate $\hat{\tau}_{\text{OLS}}$ (regressing $Y$ on $T$ and $X$) and an IPW estimator $\hat{\tau}_{\text{IPW}}$ (using propensity scores). If all three are similar, confounding is likely modest. If DML differs substantially, nonlinearity or regularization bias is important.

### Common pitfalls and how to avoid them

<WarnBox>

**Mistake**: running DML many times with different hyperparameters and selecting the one that gives the "best" $\hat{\tau}$.

**Why it's wrong**: this is **p-hacking**. You're selecting hyperparameters to maximize $\hat{\tau}$, which invalidates confidence intervals.

**Fix**: tune hyperparameters on a separate held-out set based on prediction $R^2$, not treatment effects.

</WarnBox>

**Mistake**: proceeding with DML when $R^2 < 0.05$ for treatment prediction.

- **Why it's wrong**: weak first stages amplify variance, making $\hat{\tau}$ imprecise and sensitive to outliers.
- **Fix**: add more confounders; check if treatment is actually randomized (if so, simple difference-in-means is better); use an instrumental variables approach if appropriate.

**Mistake**: running DML without verifying that $0 < P(T=1 \mid X) < 1$ for all $X$.

- **Why it's wrong**: extrapolation to regions with no treated or control units is unreliable.
- **Fix**: plot the propensity score distribution for treated and control groups; trim observations with extreme propensity scores (e.g., below 0.05 or above 0.95); report the trimmed analysis alongside main results.

**Mistake**: setting `cv=2` to speed up computation.

- **Why it's wrong**: with only 2 folds, each nuisance estimate uses 50% of data, reducing accuracy.
- **Fix**: use `cv=5` as default (good balance); increase to `cv=10` for larger datasets ($n > 5{,}000$); leave-one-out (`cv=n`) is expensive, and the fixed-$K$ argument above does not cover it.

### When to use DML vs. alternatives

```
1. Define the intervention, target population, units and horizon.
2. Identify assignment. For randomization, start with the design contrast.
   Use an IV or discontinuity only with a credible instrument or threshold.
3. Compare adjusted OLS or ANCOVA with cross-fitted nuisance adjustment
   on the same rows. For dynamic effects, define exposure histories.
4. Evaluate nuisance losses, residual treatment variation and uncertainty.
   Count independent assigning units and eligible future periods.
5. Evaluate heterogeneity or a policy on held-out outcome-based contrasts.
```

### Exercise 2.1: Verifying orthogonality (conceptual)

Consider independent Bernoulli assignment with known constant probability $0<e<1$, independent of both potential outcomes. Which observable score identifies the ATE? What changes when its weights use a different number?

**Solution.** Consistency gives $Y=TY(1)+(1-T)Y(0)$. Define the Horvitz–Thompson signal
$$
Z=TY/e-(1-T)Y/(1-e).
$$
Conditional on both potential outcomes, averaging over assignment gives $\mathbb E[Z\mid Y(1),Y(0)]=Y(1)-Y(0)$. The realized $Z$ uses one observed outcome. The equation $\mathbb E[Z-\tau]=0$ therefore identifies the ATE using only quantities known by design or observed. Optional outcome adjustment introduces nuisance functions and requires its own inference argument.

Substituting an incorrect fixed $q$ into the weights gives expectation $(e/q)\mathbb E[Y(1)]-[(1-e)/(1-q)]\mathbb E[Y(0)]$. This generally changes the target. Substituting the realized treatment fraction instead yields the usual difference in arm means when both arms are present. Conditional on their sizes, randomization makes that difference unbiased in the stated design.

### Exercise 2.2: Non-orthogonal score bias (mathematical)

For $Y=\tau_0T+g_0(X)+\epsilon$ with $\mathbb E[\epsilon\mid T,X]=0$, compare the two population moments
$$
\mathbb E[T(Y-\tau T-g(X))],\qquad
\mathbb E[(T-m(X))(Y-\tau T-g(X))].
$$
How does a perturbation $g=g_0+b$ affect each score?

**Solution.** At the true slope, the first moment changes by $-\mathbb E[Tb(X)]$. If $\mathbb E[T^2]>0$, its population root at the fitted $g$ shifts by $-\mathbb E[Tb(X)]/\mathbb E[T^2]$. A perturbation of order $n^{-1/2}$ can leave a nonzero shift on the root-$n$ scale. A shifted limiting distribution can invalidate a confidence interval centered as if there were no bias, even when the estimator remains root-$n$ consistent.

In the second moment write $m=m_0+a$, with $m_0(X)=\mathbb E[T\mid X]$. At $\tau_0$ the drift is $\mathbb E[a(X)b(X)]$, since $\mathbb E[(T-m_0)b]=\mathbb E[a\epsilon]=0$. If either nuisance is exactly known, that drift vanishes. If both errors have $L_2$ norm $O_p(n^{-1/2})$, it is $O_p(n^{-1})$. Multiplying that term by $\sqrt{n}$ makes it vanish. This is the IV-type orthogonal score.

### Exercise 2.3: Sample splitting necessity (computational)

Compare a scalar PLR fitted with cross-fitted predictions with the same score using predictions from the training observations. Use identical learner settings and the same generated data.

```python
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from dml_ts.dml import double_ml

np.random.seed(123)
n = 1000
X = np.random.randn(n, 10)
T = X[:, 0]**2 + X[:, 1] + np.random.randn(n)
Y = 3.0 * T + X[:, 0]**2 + X[:, 1]**3 + np.random.randn(n)

forest = RandomForestRegressor(n_estimators=50, max_depth=5, random_state=42)
crossfit = double_ml(Y, T, X, outcome_model=forest, treatment_model=forest,
                     n_folds=5, random_state=42)
```

**Solution.** Fit each learner on all observations and use the same through-origin residual slope.

```python
from sklearn.base import clone

t_hat = clone(forest).fit(X, T).predict(X)
y_hat = clone(forest).fit(X, Y).predict(X)
v = T - t_hat
same_sample = np.dot(v, Y - y_hat) / np.dot(v, v)
for label, est in [("Cross-fitted", crossfit.theta), ("Same sample", same_sample)]:
    print(f"{label}: {est:.3f} (absolute error {abs(est - 3.0):.3f})")
```

**Measured output**

```text
Cross-fitted: 3.174 (absolute error 0.174)
Same sample: 3.177 (absolute error 0.177)
```

These are absolute errors on one dataset. Cross-fitting removes direct reuse of a scored observation in its nuisance fit. It carries no guarantee that every single estimate lies closer to the truth. A bias or coverage comparison needs repeated independent datasets.
