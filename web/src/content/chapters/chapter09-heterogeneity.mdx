# Heterogeneity Analysis

## Introduction

Earlier chapters estimated scalar effects, including common slopes and average effects for specified populations. But in practice, treatment effects often vary across individuals or units. Understanding this **heterogeneity** is essential.

<ResultBox>

The examples use EconML for effect learning and tree fitting, plus a held-out randomization score for evaluation. The book companion supplies the insurance simulator.

</ResultBox>

Understanding heterogeneity matters for:

- **Targeting**: who benefits most from treatment?
- **Policy design**: should treatment be universal or selective?
- **Mechanism understanding**: why do effects vary?
- **External validity**: will effects generalize to new populations?

<ResultBox>

**Chapter objectives:**

- Define and estimate Conditional Average Treatment Effects (CATE).
- Discuss CausalForestDML as optional external-package methodology.
- Discuss the Best Linear Predictor (BLP) for effect heterogeneity.

### From ATE to CATE

The Average Treatment Effect answers "*what is the effect on average?*" The Conditional Average Treatment Effect answers "*what is the effect for units with characteristics $X = x$?*"

<Theorem kind="definition" n="9.1" name="Conditional Average Treatment Effect" id="def-cate">

For a unit with covariates $X = x$, the CATE is:

$$
\tau(x) = \mathbb{E}[Y(1) - Y(0) \mid X = x]
$$

The ATE is the expectation of CATE over the covariate distribution:

$$
\tau_{\text{ATE}} = \mathbb{E}[\tau(X)] = \mathbb{E}[\mathbb{E}[Y(1) - Y(0) \mid X]]
$$

</Theorem>

<InsightBox>

**Why heterogeneity matters.** Consider a training program evaluation:

- ATE: a 1,000-dollar average wage increase (statistically significant).
- But the effect is +3,000 dollars for workers without a college degree.
- And −500 dollars for workers with graduate degrees.

The subgroup shares and program costs determine how much a targeted policy gains.

</InsightBox>

## CATE theory

### Identification

CATE identification requires the same assumptions as ATE, applied conditionally:

<Theorem kind="theorem" n="9.1" name="CATE Identification" id="thm-cate-identification">

Under the following assumptions:

1. **Conditional unconfoundedness**: $(Y(0), Y(1)) \perp T \mid X$.
2. **Overlap**: $0 < P(T = 1 \mid X = x) < 1$ for all $x$ in the support.
3. **SUTVA**: no interference, single version of treatment.

the CATE is identified as:

$$
\tau(x) = \mathbb{E}[Y \mid T = 1, X = x] - \mathbb{E}[Y \mid T = 0, X = x]
$$

</Theorem>

### Estimation challenges

CATE estimation faces challenges beyond ATE:

1. **High dimensionality**: $\tau(x)$ is a function, not a scalar.
2. **Curse of dimensionality**: local estimation becomes sparse.
3. **Regularization bias**: standard ML methods induce bias in conditional means.
4. **Inference complexity**: constructing valid CIs for $\tau(x)$ requires special care.

<Theorem kind="definition" n="9.2" name="Nuisance Functions for CATE" id="def-cate-nuisance">

An outcome-regression approach uses the following conditional means. The propensity enters approaches that reweight by the assignment mechanism.

$$
\begin{aligned}
\mu_0(x) &= \mathbb{E}[Y \mid T = 0, X = x] \quad \text{(control outcome)} \\
\mu_1(x) &= \mathbb{E}[Y \mid T = 1, X = x] \quad \text{(treated outcome)} \\
e(x) &= P(T = 1 \mid X = x) \quad \text{(propensity score)}
\end{aligned}
$$

The naive CATE estimator $\hat{\tau}(x) = \hat{\mu}_1(x) - \hat{\mu}_0(x)$ inherits regularization bias from ML estimation.

</Theorem>

## DML for heterogeneous effects

Neyman orthogonality reduces first-order sensitivity to small nuisance estimation errors. Finite-sample bias, weak treatment variation and misspecified effect models can still affect recovery.

### The R-learner framework

<Theorem kind="definition" n="9.3" name="R-Learner for CATE" id="def-r-learner">

The R-learner (Nie and Wager, <Cite key="nie2021quasi" />) minimizes a weighted squared loss:

$$
\hat{\tau}(\cdot) = \argmin_{\tau \in \mathcal{T}} \sum_{i=1}^{n} \left( \underbrace{Y_i - \hat{m}(X_i)}_{\text{residualized } Y} - \underbrace{(T_i - \hat{e}(X_i))}_{\text{residualized } T} \cdot \tau(X_i) \right)^2
$$

where $\hat{m}(x)$ estimates the conditional mean $\mathbb{E}[Y \mid X=x]$ averaging over the observed assignment mechanism.

</Theorem>

The R-learner fits a candidate effect function using held-out nuisance predictions.

1. Residualize $Y$ on $X$: $\tilde{Y}_i = Y_i - \hat{m}(X_i)$.
2. Residualize $T$ on $X$: $\tilde{T}_i = T_i - \hat{e}(X_i)$.
3. Regress $\tilde{Y}$ on $\tilde{T} \cdot \tau(X)$.

### Implementation with EconML

EconML provides established external implementations:

```python
import numpy as np
from econml.dml import LinearDML, CausalForestDML
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier

# Two independent sets of people in a randomized experiment, p = 0.5.
rng = np.random.default_rng(42)
features = rng.normal(size=(2000, 5))
assigned = rng.binomial(1, 0.5, len(features))
truth = 1 + 2 * features[:, 0]
outcomes = (truth * assigned + features @ [1, 0.5, -0.3, 0.2, 0.1]
            + rng.normal(size=len(features)))
X_train, X_eval = np.split(features, [1200])
T_train, T_eval = np.split(assigned, [1200])
Y_train, Y_eval = np.split(outcomes, [1200])
tau_eval = truth[1200:]  # Known only in this simulation.

outcome_model = RandomForestRegressor(n_estimators=100, random_state=42,
                                      n_jobs=1)
treatment_model = RandomForestClassifier(n_estimators=100, random_state=42,
                                         n_jobs=1)
est_linear = LinearDML(model_y=outcome_model, model_t=treatment_model,
                       discrete_treatment=True, cv=5, random_state=42)
est_linear.fit(Y_train, T_train, X=X_train[:, :2], W=X_train[:, 2:])
cate_linear = est_linear.effect(X_eval[:, :2])
```

<InsightBox>

**X vs W in EconML.** EconML distinguishes:

- **X (effect modifiers)**: variables the CATE depends on — $\tau(X)$.
- **W (controls)**: variables needed for unconfoundedness but not effect heterogeneity.

Putting everything in X leads to the curse of dimensionality. Putting effect modifiers in W throws away heterogeneity information. Good practice: domain knowledge guides the split.

</InsightBox>

## CausalForestDML

A forest can represent nonlinear effect modifiers and interactions whose form is unknown. CausalForestDML combines random forests with DML orthogonalization.

### Theory

<Theorem kind="definition" n="9.4" name="Causal Forest" id="def-causal-forest">

A causal forest (Wager and Athey, <Cite key="wager2018estimation" />) is a random forest where:

1. Splits use treatment variation and outcome information to distinguish local treatment responses.
2. Predictions are **honest**: separate observations determine splits and estimate leaf effects.
3. Local estimates use a neighborhood weighted by tree proximity.

A stylized split gain for equally sized leaves with equal treatment variance depends on the difference in leaf slopes. Actual weights and split criteria depend on the forest implementation.

$$
\text{Heterogeneity gain} \propto (\hat{\tau}_{\text{left}} - \hat{\tau}_{\text{right}})^2
$$

</Theorem>

CausalForestDML adds DML orthogonalization: first residualize $Y$ and $T$, then fit a causal forest to the residuals.

### Implementation

```python
est_cf = CausalForestDML(
    model_y=outcome_model, model_t=treatment_model, discrete_treatment=True,
    n_estimators=200, min_samples_leaf=10, honest=True, inference=True,
    cv=5, random_state=42, n_jobs=1,
)
est_cf.fit(Y_train, T_train, X=X_train)
cate_pred = est_cf.effect(X_eval)
cate_lower, cate_upper = est_cf.effect_interval(X_eval, alpha=0.05)
print("Held-out CATE RMSE:", np.sqrt(np.mean((cate_pred - tau_eval)**2)))
```

### Inference

Under the forest inference assumptions, `effect_inference` supplies pointwise uncertainty for conditional mean effects at prespecified evaluation profiles. The randomized example uses independent people.

```python
# Detailed inference for conditional means at five prespecified covariate profiles
inference_results = est_cf.effect_inference(X_eval[:5])
summary_df = inference_results.summary_frame(alpha=0.05)
print(summary_df)

# Columns: point_estimate, stderr, zstat, pvalue, ci_lower, ci_upper

# Population summary
pop_summary = est_cf.effect_inference(X_eval).population_summary(alpha=0.05)
print(pop_summary)
```

## Best Linear Predictor of CATE

While $\hat{\tau}(x)$ gives individual predictions, the **Best Linear Predictor** (BLP) summarizes heterogeneity in an interpretable way.

### Theory

<Theorem kind="definition" n="9.5" name="Best Linear Predictor" id="def-blp">

The BLP projects the true CATE onto a linear function of effect modifiers:

$$
\tau_{\text{BLP}}(X) = \alpha^* + X'\beta^*
$$

where $(\alpha^*,\beta^*) = \argmin_{\alpha,\beta} \mathbb{E}[(\tau(X) - \alpha - X'\beta)^2]$.

The BLP answers: "Which covariates *linearly* predict effect heterogeneity?"

</Theorem>

<Theorem kind="theorem" n="9.2" name="BLP Interpretation" id="thm-blp-interpretation">

The BLP coefficient $\beta^*_j$ measures the **partial linear association** between covariate $X_j$ and the treatment effect $\tau(X)$, holding other covariates fixed (in a linear projection sense).

</Theorem>

### Implementation

The CATE intercept gives the fitted effect at zero modifiers. The evaluation-cohort mean averages the fitted effects at its observed modifiers.

```python
print(est_linear.summary())
print("Fitted effect at zero modifiers:", float(np.asarray(est_linear.intercept_).item()))
print("Average fitted effect in evaluation cohort:", float(est_linear.ate(X_eval[:, :2])))
```

### A held-out test of a heterogeneity prediction

Freeze a prediction $S(X)$ on the separate training sample. For independent Bernoulli assignments with known probability $p(X)$, the transformed response $Z=(T-p(X))Y/[p(X)(1-p(X))]$ satisfies $\mathbb{E}[Z\mid X]=\tau(X)$. Regress $Z$ on an intercept and the centered prediction in the evaluation cohort. The slope projects $\tau(X)$ onto $S(X)$, conditional on the fitted prediction rule. A zero slope can occur when a real modifier is unrelated to the predictor. A slope of one assesses its scale and the intercept estimates the mean effect in this centered regression. Compare the mean forecast with that intercept to assess level calibration.

This single-split illustration uses a known randomization probability and independent people. Clustered assignments or repeated temporal decisions require uncertainty appropriate to the design. Chernozhukov, Demirer, Duflo and Fernández-Val develop related projections with adjustment and aggregation across splits. [Published methodology](https://doi.org/10.3982/ECTA19303).

```python
import statsmodels.api as sm

def randomized_effect_score(y, treatment, propensity):
    """An unbiased response for the conditional effect under known randomization."""
    y = np.asarray(y, dtype=float)
    treatment = np.asarray(treatment)
    p = np.broadcast_to(np.asarray(propensity, dtype=float), y.shape)
    if (y.ndim != 1 or treatment.shape != y.shape or not np.isfinite(y).all()
            or not np.isin(treatment, [0, 1]).all() or not np.isfinite(p).all()
            or np.any((p <= 0) | (p >= 1))):
        raise ValueError("Require aligned outcomes, binary assignments and 0 < p < 1")
    return (treatment - p) * y / (p * (1 - p))

def heldout_blp(prediction, effect_score):
    """Project a randomized evaluation response on a frozen prediction."""
    s = np.asarray(prediction, dtype=float)
    if (s.ndim != 1 or len(s) < 3 or s.shape != np.shape(effect_score)
            or not np.isfinite(s).all() or np.ptp(s) == 0):
        raise ValueError("Require aligned observations and a varying prediction")
    design = sm.add_constant(s - s.mean())
    return sm.OLS(effect_score, design).fit(cov_type="HC2")

eval_score = randomized_effect_score(Y_eval, T_eval, 0.5)
blp = heldout_blp(cate_pred, eval_score)
print("Slope, robust SE, p-value:", blp.params[1], blp.bse[1], blp.pvalues[1])
```

### Partial dependence plots

The curve averages fitted effects at a fixed feature value over the evaluation distribution of the other features. Restrict the grid to combinations with substantive support. A confidence interval for this curve requires the joint uncertainty of the averaged predictions. The example plots the fitted mean alone.

```python
def plot_cate_partial_dependence(est, X, feature_idx, feature_name, n_grid=50):
    """Average fitted effects over the empirical distribution of other features."""
    x_grid = np.linspace(*np.quantile(X[:, feature_idx], [0.05, 0.95]), n_grid)
    means = []
    for value in x_grid:
        modified = X.copy()
        modified[:, feature_idx] = value
        means.append(est.effect(modified).mean())
    plt.figure(figsize=(8, 5))
    plt.plot(x_grid, means)
    plt.xlabel(feature_name)
    plt.ylabel("Average fitted effect")
    plt.tight_layout()
    return x_grid, np.asarray(means)

x_grid, mean_effect = plot_cate_partial_dependence(est_cf, X_eval, 0, "X_0")
```

## Subgroup analysis and policy trees

Heterogeneity analysis often culminates in **actionable subgroups** — identifying who should receive treatment.

### CATE-based subgroups

```python
# Group boundaries are frozen using training features. Evaluation outcomes
# provide a design-based comparison within each supported group.
cuts = np.unique(np.quantile(est_cf.effect(X_train), [0.25, 0.50, 0.75]))
groups = np.digitize(cate_pred, cuts)
feature_names = [f"X_{j}" for j in range(X_train.shape[1])]
for group in np.unique(groups):
    use = groups == group
    counts = np.bincount(T_eval[use], minlength=2)
    print("Group, arm counts, mean prediction:", group, counts, cate_pred[use].mean())
    if counts.min() >= 2:
        print("Randomized score mean, SE:", eval_score[use].mean(),
              eval_score[use].std(ddof=1) / np.sqrt(use.sum()))
```

### Policy trees for treatment assignment

Fit a depth-limited candidate rule on the training people, then evaluate it in the independent randomized cohort. All decisions and the cost are frozen before inspecting evaluation outcomes.

```python
from econml.cate_interpreter import SingleTreePolicyInterpreter

cost = 0.2  # Cost of one treatment in outcome units.
policy = SingleTreePolicyInterpreter(
    max_depth=2, min_samples_leaf=100, random_state=42,
)
policy.interpret(est_cf, X_train, sample_treatment_costs=cost)
assign_policy = policy.treat(X_eval)
# Incremental net value versus treating nobody on the evaluation population.
net_gain = assign_policy * (eval_score - cost)
print("Fraction selected:", assign_policy.mean())
print("Policy gain, SE:", net_gain.mean(), net_gain.std(ddof=1) / np.sqrt(len(net_gain)))
print("Treat-all gain:", (eval_score - cost).mean())
paired_gain = (assign_policy - 1) * (eval_score - cost)
print("Gain versus treating all, SE:", paired_gain.mean(),
      paired_gain.std(ddof=1) / np.sqrt(len(paired_gain)))
```

<InsightBox>

**Policy trees vs. prediction trees.** **Prediction trees** minimize squared error in predicting $\tau(x)$. They may include irrelevant splits if they marginally improve prediction. A policy tree fits a restricted rule to estimated net benefits. Independent randomized outcomes support a comparison with treating everyone or nobody. A useful ranking can still have poor value at a given cost or capacity.

</InsightBox>

## Application: insurance pricing heterogeneity

Score the fitted response to a one-basis-point competitor price change in months 90 through 119, holding the three previous rates fixed. The moderate generator has a common direct effect across products. The full generator varies the effect by product and regime. All nuisance fitting stays within months before 90. Its three retrospective date folds exclude a three-month buffer on either side of each inner validation block. The outer evaluation concerns later months for the same 20 products. Use the simulated truth to measure causal error on this path.

```python
from dml_ts.validation import create_insurance_dgp

def evaluate_insurance(realism):
    dgp = create_insurance_dgp(realism=realism, n_periods=120,
                               n_products=20, true_tau=-0.8, seed=42)
    rows, lagged_rates = dgp.treatment_history(3)
    month = dgp.time_index[rows]
    product = dgp.product_index[rows]
    modifiers = np.column_stack([np.eye(20)[product], month])
    controls = np.column_stack([dgp.X_macro[rows], lagged_rates,
                                np.sin(2 * np.pi * month / 4)])
    train = month < 90
    train_month = month[train]
    folds = []
    for block in np.array_split(np.unique(train_month), 3):
        score = np.flatnonzero(np.isin(train_month, block))
        fit = np.flatnonzero((train_month < block[0] - 3) |
                             (train_month > block[-1] + 3))
        folds.append((fit, score))
    forest = CausalForestDML(model_y=outcome_model, model_t=outcome_model,
                             n_estimators=200, min_samples_leaf=10, cv=folds,
                             random_state=42, n_jobs=1, inference=False)
    forest.fit(dgp.Y[rows][train], dgp.T[rows][train],
               X=modifiers[train], W=controls[train])
    predicted = forest.effect(modifiers[~train])

    # Reveal the generator's direct effect only after prediction.
    pars = dgp.true_params
    actual = np.full(len(predicted), pars.tau)
    if pars.tau_by_product is not None:
        actual = pars.tau_by_product[product[~train]] * (
            1 + pars.regime_shift * (month[~train] >= pars.regime_shift_period))
    return np.sqrt(np.mean((predicted - actual)**2)), predicted.std(), actual.std()

insurance_results = {level: evaluate_insurance(level) for level in ("moderate", "full")}
for level, result in insurance_results.items():
    print(level, "RMSE, predicted SD, true SD:", result)
```

1. **CATE**: $\tau(x) = \mathbb{E}[Y(1) - Y(0) \mid X = x]$ is a conditional mean effect for a covariate profile.
2. **DML for CATE**: orthogonal scores reduce first-order sensitivity to nuisance error.
3. **CausalForestDML**: optional external-package method for non-parametric heterogeneity.
4. **BLP**: optional linear summary of heterogeneity for interpretation and testing.
5. **Policy trees**: optional rules for treatment targeting.

<ResultBox>

- Heterogeneity reveals who benefits from treatment — essential for targeting.
- CausalForestDML is discussed through EconML, not implemented in this repo.

</ResultBox>
